# Raw data

Store the original ICCAT input files used in Chapter 1 here.

Rules:

- Never edit raw files manually.
- Preserve the original filename and format.
- Record the source URL, download date, version, and checksum.
- Keep Task I, Task II, and reference tables separate.
- Do not commit confidential data or files that exceed GitHub size limits.

Planned contents:

- `task1/`: nominal catch data.
- `task2/`: catch-and-effort data.
- `reference/`: species, gear, fleet, stock, and reporting-category codes.
