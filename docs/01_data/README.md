# Chapter 1: DATA documentation

This directory records the information needed to understand and reproduce the reporting analyses.

Planned documentation:

- data inventory and provenance;
- data dictionary;
- ICCAT code mappings;
- inclusion and exclusion criteria;
- treatment of zeros, missing values, and unknown categories;
- taxonomic-resolution rules;
- definitions of landings, dead discards, and live releases;
- analytical decisions and deviations from the protocol.
