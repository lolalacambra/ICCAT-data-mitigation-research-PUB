# ICCAT DATA–MITIGATION–RESEARCH

Reproducible analyses for Chapter 1 of the study evaluating the evolution of ICCAT conservation and management measures for pelagic sharks and rays.

The chapter is organized into three components:

1. **DATA**: reporting requirements, Task I nominal catches, taxonomic resolution, reporting components, and Task II catch-and-effort availability.
2. **MITIGATION**: adoption of scientifically supported mitigation measures.
3. **RESEARCH**: alignment between CMM research priorities and subsequent scientific production.

## Current directory structure

```text
data/
  raw/                 Original input files; never modified manually
  processed/           Analysis-ready datasets generated by scripts
R/
  01_data/             Ordered scripts for the DATA component
outputs/
  01_data/             Generated tables, figures, and diagnostics
docs/
  01_data/             Data provenance, dictionaries, rules, and decisions
```

## Reproducibility rules

- Run the project from the `.Rproj` file.
- Use project-relative paths only.
- Preserve raw data unchanged.
- Generate processed data and outputs exclusively through scripts.
- Number scripts in execution order.
- Document every source, version, assumption, and exclusion.
- Commit code and documentation in small, descriptive changes.

## Starting the DATA component

1. Place the original ICCAT files in the appropriate location under `data/raw/`.
2. Complete the data inventory and provenance record.
3. Inspect file structure before writing cleaning code.
4. Develop and validate the scripts in `R/01_data/`.
5. Save generated datasets in `data/processed/` and results in `outputs/01_data/`.
